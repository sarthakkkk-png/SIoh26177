# Sample images

`bus.jpg` — public demo image from the Ultralytics YOLO project assets
(https://github.com/ultralytics/ultralytics, AGPL-3.0). It is the standard
public YOLO sample and is used here only to verify that real model inference
runs end-to-end and produces canonical detection records.

It is a ground-level street scene, not an aerial image. No aerial or
search-and-rescue detection accuracy is claimed from it.
